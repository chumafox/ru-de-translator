# Технический аудит

Дата: 2026-08-13. Проверенная версия: 0.3.0.

## Резюме

До аудита проект содержал несколько блокирующих проблем: установка из корня не могла найти `pyproject.toml`, CTranslate2-модель скачивалась, но не конвертировалась в ожидаемый формат, импорт TTS безусловно требовал MLX даже на Linux, а модуль TTS глобально подменял `subprocess.Popen`. Также UI при каждом запуске пытался поднять Ollama независимо от выбранного провайдера.

В ходе аудита исправлены эти проблемы, стандартизирована упаковка, ограничено потребление памяти, добавлена валидация конфигурации и создан базовый изолированный test suite.

## Исправленные критические проблемы

### Установка и упаковка

- `pyproject.toml` перенесён в корень и настроен на стандартный пакет `ru_de_translator`.
- Добавлен рабочий launcher `./rude`.
- Установщик теперь не зависит от текущей директории, использует strict mode и выдаёт понятную ошибку при отсутствии FFmpeg.
- Добавлен реальный pipeline подготовки модели: загрузка токенизатора, конвертация OPUS-MT и int8-квантизация.
- Тяжёлый Apple-only стек MLX вынесен в optional extra `qwen`; обычная установка стала переносимой.
- Удалены устаревший lock-файл с прежним графом зависимостей, бинарный тестовый MP3, crash dump и скрипт с абсолютным путём конкретного разработчика.
- Сломанная абсолютная ссылка `AGENTS.md` заменена переносимым файлом.

### Надёжность и конкурентность

- CTranslate2 загрузка, инференс и выгрузка защищены одним lock: параллельный перевод больше не гоняется с unload.
- HTTP-клиент переиспользует соединения и корректно закрывается при выходе/смене настроек.
- translateLocally принудительно завершается при timeout, что исключает потерянные процессы.
- Старые Translator/TTS освобождаются после смены настроек; ранее модели могли оставаться в RAM.
- Фоновые задачи отменяются на выходе, ошибки задач логируются.
- Ollama больше не запускается скрыто и не создаёт 15-секундную фоновую задержку на каждом старте.
- Повторные TTS-вызовы сериализованы, Edge-аудио кэшируется, оба LRU-кэша ограничены 30 элементами.
- История экспорта ограничена 50 записями.

### Безопасность и приватность

- Gemini API key перенесён из query string в заголовок `x-goog-api-key`, чтобы не попадать в URL-логи и proxy history.
- Конфигурация записывается атомарно с mode `0600`, директория — `0700`.
- Ответ модели показывается без Rich markup; сообщения статуса экранируются. Это устраняет markup injection через внешний ответ.
- Удалена глобальная monkey-patch подмена `subprocess.Popen` и запись traceback в абсолютный пользовательский путь.
- Логи ограничены ротацией: 1 МБ × 4 файла вместо неограниченного роста.

### Корректность

- Исправлено расхождение `ctranslate2_tokenizer_name`/`ctranslate2_tokenizer_path`; добавлена миграция старой настройки.
- Число повторов и пауза валидируются и ограничиваются безопасными диапазонами.
- Исправлен экспорт float32 PCM: теперь данные преобразуются в int16, а не ошибочно интерпретируются pydub как int32.
- Заголовок UI показывает фактически выбранный TTS-провайдер и голос.
- Добавлены проверки пустых/слишком больших запросов и пустых ответов провайдеров.
- Ошибки HTTP и повреждённый JSON преобразуются в контролируемый `TranslationError`.

## Проверки

В sandbox успешно выполнены:

- `pytest`: 7 тестов;
- Ruff lint для production-кода, новых тестов и setup script;
- Ruff format check;
- `compileall`;
- сборка wheel;
- импорт приложения на Linux без MLX;
- Textual headless smoke test;
- `bash -n` для installer и launcher.

Unit-тесты покрывают миграцию/валидацию конфигурации, атомарное сохранение, восстановление после повреждённого JSON, dispatch и HTTP errors, удаление Ollama reasoning blocks и отсутствие Gemini key в URL.

## Остаточные риски и рекомендации

1. **Качество модели.** Нужен отдельный golden dataset RU→DE и метрики COMET/BLEU; функциональные тесты не оценивают лингвистическое качество.
2. **Интеграция моделей.** Полный CTranslate2/Qwen тест требует скачивания моделей и целевого Apple Silicon устройства; в CI его следует запускать отдельно и по расписанию.
3. **Аудиоустройства.** Unit-тесты не могут гарантировать работу конкретного CoreAudio/PulseAudio устройства. Нужен ручной smoke test на поддерживаемых ОС.
4. **Benchmark.** Qwen benchmark перенесён в `benchmarks/` и требует Apple Silicon и optional extra; он не запускается в обычном CI.
5. **Секреты.** API key по требованию продукта пока хранится локально в config. Следующий уровень защиты — системный Keychain/keyring.
6. **Lock-файл.** После принятия новой структуры следует генерировать и обновлять корневой `uv.lock` в поддерживаемой среде командой `uv lock`.
