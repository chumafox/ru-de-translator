# RU-DE Translator (rude)

⚡️ **Ультрабыстрый терминальный переводчик с русского на немецкий (с озвучкой)**

RU-DE Translator (`rude`) — это минималистичный и молниеносный оффлайн-переводчик-тренажер, работающий прямо в вашем терминале. Он создан для тех, кто учит немецкий язык и хочет мгновенно переводить фразы и тренировать их произношение, не отвлекаясь на браузер и тяжелые приложения.

![Screenshot](screenshot.png) <!-- Добавьте скриншот интерфейса сюда -->

## 🚀 Особенности

- **Оффлайн-перевод:** Использует движок `CTranslate2` и легковесную нейросетевую модель `Helsinki-NLP/opus-mt-tc-big-zle-de`. Перевод выполняется локально на вашем процессоре за миллисекунды.
- **Гибридная озвучка (TTS):** 
  - *Primary:* Высококачественный нейросетевой голос через API Microsoft Edge TTS.
  - *Fallback:* Встроенный локальный голос macOS (`say -v Anna`), который мгновенно подхватывается при отсутствии интернета или блокировках.
- **Режим "Практика":** Автоматический повтор фразы заданное количество раз с паузами для отработки произношения.
- **Экспорт в MP3:** Сохраняйте тренировочные сессии в аудиофайлы на Рабочий стол по одному нажатию.
- **Terminal UI:** Красивый и отзывчивый интерфейс на базе фреймворка `Textual`.

## 💻 Системные требования

Проект изначально оптимизирован под использование на **macOS** (особенно Apple Silicon M-серии).

### Минимальное железо
- **RAM:** 8 GB
- **SSD:** ~1.5 GB свободного места (для моделей, Python-окружения и ffmpeg)
- **CPU:** Apple Silicon (M1+) или Intel Core i5+

### Зависимости (устанавливаются автоматически)
- **Python:** 3.10 или выше
- **FFmpeg:** для воспроизведения и склейки аудио (`ffplay`)
- **Менеджер пакетов:** `uv` (рекомендуется для сверхбыстрой установки)

## 🛠 Установка (Автоматическая)

Для "крутых девопсов" и любителей автоматизации в проекте предусмотрен умный скрипт установки, который сам проверит железо, покажет уведомления и установит все зависимости.

Просто выполните в терминале:

```bash
chmod +x install.sh
./install.sh
```

**Что делает `install.sh`:**
1. Проверяет наличие необходимого объема RAM (минимум 8GB).
2. Проверяет свободное место на диске.
3. Если требования не выполнены — показывает нативное всплывающее уведомление macOS.
4. Проверяет и устанавливает `Homebrew` (если его нет).
5. Устанавливает `ffmpeg` (через brew).
6. Проверяет наличие Python-утилиты `uv` (ставит при необходимости).
7. Создает виртуальное окружение, скачивает все нужные python-библиотеки и модели.

## ⌨️ Использование

После установки запустите программу:

```bash
./rude
# или
uv run python -m ru_de_translator.app
```

### Горячие клавиши (Hotkeys)
- `Enter` — Перевести текст
- `Ctrl+P` — Озвучить текущий перевод
- `Alt+R` — Запустить режим "Практика" (повтор фразы)
- `Ctrl+S` — Остановить любую текущую озвучку
- `Ctrl+E` — Экспортировать историю озвучек в MP3 на Рабочий стол
- `F1` — Открыть окно настроек
- `Ctrl+Q` — Мгновенно закрыть программу

---

## ⚙️ Настройки (F1)

Внутри программы (по кнопке F1) вы можете настроить:
- Провайдера перевода (по умолчанию `CTranslate2` - оффлайн).
- Механизм озвучки (`Edge TTS` или `Qwen3-TTS`).
- Голос Edge TTS (по умолчанию Katja).
- Количество повторов в режиме практики и паузу между ними.
- Включение/отключение автоматической озвучки сразу после перевода.

## 💡 Решение проблем

**При вводе текста (особенно при голосовом наборе) вставляются цифры вместо букв**
> Если вы используете сторонние утилиты для диктовки/вставки текста (например, Handy), переведите их из режима "Эмуляция нажатий клавиатуры" (Simulate keystrokes) в режим "Вставка через буфер обмена" (Paste via Clipboard). Терминал работает в Bracketed Paste Mode, и посимвольная эмуляция Unicode-символов с зажатой клавишей Option(Alt) может распознаваться терминалом как цифры.
